# 🧪 Software Testing & Quality Assurance (SQA) Activities

> A comprehensive repository containing practical lab assignments, test execution reports, manual test cases, static testing reviews, and API testing artifacts completed as an SQA Trainee.

---

## 📌 Overview

This repository serves as a structured portfolio of hands-on Software Quality Assurance activities. It covers end-to-end testing methodologies ranging from Agile framework evaluation and SRS requirement reviews to manual test case design, exploratory testing charters, dynamic white-box testing, and API response validation.

---

## 📂 Repository Structure & Deliverables

### 1. 🔄 Agile & SDLC Frameworks
* `Day01_Activity01_FrameworkSelection.docx` – Evaluation and selection criteria for SDLC frameworks.
* `Day01_Activity02_ScrumNoScrumKanbanNoKanbanXpNoXP.docx` – Comparative analysis of Scrum, Kanban, and XP methodologies.
* `Day01_Activity03_ClassifyBacklogItems.docx` – Classification and prioritization of backlog items/user stories.

### 2. 📑 Static Testing & Requirement Analysis
* `Detailed_SRS_Student_Review_Exercise.docx` – Detailed review exercise for Software Requirement Specifications.
* `SRS_Highlighted_Review.docx` – Annotated SRS document highlighting ambiguities and missing requirements.
* `SRS_Review_Report.docx` – Formal review report summarizing requirement defects and recommendations.
* `identify bug.docx` – Requirement bug logging and identification document.

### 3. 📝 Test Design & Test Case Execution
* `04_CTFL_Test Design Techniques 1 (1).docx` – ISTQB CTFL black-box and structure-based test design techniques.
* `Smoke Test.xlsx` – Smoke test suite and verification execution status.
* `TASK-04 Automation Exercise Test Cases.xlsx` – Functional test suite for Automation Exercise scenarios.
* `Task-Test Case Writing and Review .xlsx` – Test case design, execution logs, and peer review records.
* `Test cases webdriver university.xlsx` – Manual test case suite for WebDriver University web application.

### 4. 🧭 Exploratory Testing Charters
* `Template-Exploratory-testing-charter-Simple-v1.docx` – Standard exploratory testing charter template.
* `02 - Lab Assignment - Exploratory Testing Charter_template_02 1.docx` – Core exploratory testing lab assignment.
* `Login 02 - Lab Assignment - Exploratory Testing Charter_template_02 1 (2).docx` – Exploratory charter for Login workflow.
* `Registration 02 - Lab Assignment - Exploratory Testing Charter_template_02.docx` – Exploratory charter for User Registration workflow.
* `Checkout 02 - Lab Assignment - Exploratory Testing Charter_template_02 1.docx` – Exploratory charter for Checkout/Payment process.

### 5. 🔬 Dynamic & White-Box Testing
* `White-box (Dynamic)- Assignment-04 1 (1).docx` – Dynamic white-box testing concepts, control flow graphs, and coverage metrics.

### 6. 🌐 API Testing
* `status codes postman.pdf` – Postman API request execution logs and output responses for standard HTTP status codes (2xx, 4xx, 5xx).
